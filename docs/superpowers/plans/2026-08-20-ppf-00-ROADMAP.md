# TEAM PERI PERI FRIES — Phase Roadmap

> **For agentic workers:** This is the index. Each phase has its own plan file in
> this directory. Execute phases in the order below. REQUIRED SUB-SKILL for each
> phase plan: `superpowers:subagent-driven-development` (recommended) or
> `superpowers:executing-plans`.

**Goal:** Ship a demoable judicial digital-evidence examination engine that emits a
log₁₀ likelihood ratio, a tamper mask, an Evidence Fragility Index, a mandatory
abstention path, a hash-sealed replayable record, and a Section 63(4)-shaped PDF.

**Spec:** `CLAUDE.md` (repo root) — authoritative. This roadmap does not restate it,
it schedules it.

**Locked decision 1 — Python 3.12, not 3.11.** CLAUDE.md says 3.11; 3.11 is not
installed and installing it costs time we do not have. 3.12 has wheels for every
pinned dependency (torch, reportlab, c2pa-python, opencv, timm). Recorded as a
stated deviation in `artifacts/environment.json` and on the report's Methods page.

**Locked decision 2 — CPU torch here, CUDA 12.8 torch there.** The dev box installs
`torch --index-url https://download.pytorch.org/whl/cpu`. Every inference wrapper
takes a `device` argument and defaults to `cpu`. Nothing in the CPU track may import
CUDA-only APIs. The training box gets the cu128 wheels from CLAUDE.md section 1 verbatim.

**Locked decision 3 — Stage B trains on a self-built splice corpus.** No FF++ EULA
wait. `train/build_corpus.py` synthesises splices with exact ground-truth masks from
authentic source clips. Corpus ID `PPF-ICV-1`. It is labelled, in the report and
on stage, verbatim as: *"internal validation corpus, not a public benchmark."*
Never described as FF++, never compared to published FF++ numbers.

**Locked decision 4 — Tailwind is vendored, not CDN.** CLAUDE.md section 9 says Tailwind
CDN; CLAUDE.md section 1 says no network at demo time. These conflict. Resolution: fetch
the Tailwind browser build **once** during Phase 8 into `web/vendor/tailwind.js`, serve it
from FastAPI's static mount, and reference it with a relative path. The frontend
stays a single authored HTML file. Demo works with the wifi off.

**Locked decision 5 — GPU handoff is a directory, not a dependency.** The CPU track
never blocks on training. Every model wrapper loads from `artifacts/*.pt` if present
and falls back to a deterministic classical operator (SRM residual for Stage A,
threshold decoder for Stage B, moving-window statistic for Stage C) if absent. The
fallback path is the one we rehearse. Checkpoints are a hot-swap upgrade.

## 4. Hour-14 kill switch

**Trigger:** at wall-clock hour 14, if `artifacts/stage_a_videoprint.pt` does not exist
or does not visibly separate a spliced region on the demo clip.

**Action:** ship Stage B on SRM residuals. Do not mention Stage A on stage. Change the
Videoprint toggle label to "acquisition residual" (which is what SRM is — accurate,
not a hedge). Spend the recovered hours on Phase 9 and Phase 10.

**The kill switch is exercised, not assumed.** Phase 5 Task 8 runs the whole pipeline
with `artifacts/` emptied and asserts a complete findings JSON still comes out.

## 6. Cross-cutting invariants

Every phase plan restates the ones it touches; they are collected here so no phase
can claim it did not know.

- **Determinism.** Fixed seeds. `json.dumps(…, sort_keys=True, separators=(",",":"))`
  for anything hashed. All floats pass through `q(x) = float(f"{x:.6f}")` before
  serialisation. Replay hash equality is a test, not an aspiration.
- **Findings hash excludes volatile fields.** Timestamps, wall-clock durations,
  absolute paths, and hostname are stripped by `canonical_findings()` before hashing.
  They still appear in the ledger and the report — just not in the hash.
- **Score convention.** Every stream score is oriented so that **higher means Hd**
  (manipulation). A stream that naturally points the other way is negated at its
  wrapper boundary, never inside the LR layer.
- **Never a percentage where an LR belongs.** Enforced by review in Phase 8 and by the
  language gate in Phase 10.
- **Forbidden strings** (CLAUDE.md section 8) are grepped in CI from Phase 10 onward, over
  `peri/`, `api/`, `train/`, `tools/`, `web/` only — with word boundaries, so
  `improves` and `approves` do not trip the `proves` rule.
- **Fragility transforms are disjoint from training augmentations.** Different
  transform families, different parameter ranges, asserted in code (Phase 4, Task 5),
  both sets printed in the report's Methods page.
- **We sign nothing.** The Part-B sheet is a DRAFT input sheet for a human expert.
